# skilltree

SkillTree (PyPI `agent-skilltree`, import `skilltree`): turns a flat folder of agent skills into a coordinate-addressed
tree an agent walks one layer at a time, keeps it coherent (`discover` · `cohere` · `emit` · `validate` · `watch`), and
binds frameworks into a SkillTome (`fold` · `project`). The substrate ChainCompiler and SkillTome build on. This
folder is its source home; `sancovp/skilltree` and PyPI are its published output. The package's own documentation is
`README.md`; the code is `src/skilltree/`, its tests `tests/`, its two papers `papers/`.
